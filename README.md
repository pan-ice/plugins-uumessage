# 群友语录

MaiBot 第三方插件，实现 QQ 群内图片投稿与随机语录功能。

## 功能

- **`/投稿`**：回复一条含图片的消息，将该图片投稿到本群语录库
- **`/群友语录`**：随机发送一条本群投稿的语录图片

## 特性

- 仅支持 QQ 群聊，私聊不可用
- 各群数据隔离，语录只在本群内共享
- 自动去重，同一图片不会重复投稿
- 每群默认最多 500 条语录，超出自动清理最旧记录（可在配置中调整）

## 安装

将本仓库内容放入 MaiBot 的 `plugins/group-quotes/` 目录：

```
plugins/group-quotes/
├── _manifest.json
├── plugin.py
├── config.toml
└── .gitignore
```

重启 MaiBot 即可自动加载。

## 配置

编辑 `config.toml`：

```toml
[plugin]
enabled = true        # 是否启用插件
config_version = "1.0.0"

[limits]
max_quotes_per_group = 500  # 每群最大语录数量
```

也可在 WebUI 插件管理页面中修改配置。

## 使用方法

### 投稿语录

1. 在群聊中找到一张你想投稿的图片消息
2. **回复**该图片消息，并发送 `/投稿`
3. 插件会保存图片并返回"投稿成功！"

> 注意：必须回复含图片的消息，仅发送 `/投稿` 无法投稿。

### 获取语录

1. 在群聊中发送 `/群友语录`
2. 插件会随机发送一张本群投稿的语录图片

### 限制

- 仅在群聊中生效，私聊发送会被拒绝
- 同一图片在同一群中只能投稿一次
- 每群最多保存 `max_quotes_per_group` 条语录

## 数据存储

- 图片文件：`plugins/group-quotes/data/images/{group_id}/{hash}.png`
- 索引数据库：`plugins/group-quotes/data/quotes.db`
- `data/` 目录已被 `.gitignore` 忽略，不会提交到仓库

## 故障排查

| 问题 | 原因 | 解决方式 |
|------|------|----------|
| 发送 `/投稿` 无响应 | 命令未被识别 | 确认插件已启用，重启 MaiBot |
| 提示"请回复一张图片来投稿" | 消息中没有回复 | 必须回复含图片的消息再发送 `/投稿` |
| 提示"被回复的消息中没有图片" | 回复的消息不含图片 | 只能投稿图片消息 |
| 提示"这张图片已经投稿过了" | 同一图片已投稿 | 同一图片每群只保存一次 |
| 提示"本群还没有语录" | 该群尚未有投稿 | 先用 `/投稿` 投稿图片 |
| 提示"无法获取图片数据" | 被引用消息过久，图片数据已被清理 | 尽快投稿新收到的图片 |
